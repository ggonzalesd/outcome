# Outcome v0.1.1

Patch release for editor configuration and consistent project formatting. The Result and Option
public API and runtime behavior are unchanged from [v0.1.0](v0.1.0.md).

## Changes

- VS Code discovers separate library and test/tooling TypeScript projects through the central
  configuration. Tests and scripts resolve Bun types while the library retains pure-source checks.
- Prettier 3.9.9 is pinned as a development dependency, with shared configuration, format-on-save
  settings, and write/check commands through Bun, Make, and mise. Regular verification includes
  formatting, and the existing code and tooling have a consistent formatting baseline.
- The package version is 0.1.1. Distribution remains TypeScript source for Bun through GitHub,
  with MIT licensing and no runtime dependencies or installation-time build hooks.

## Install

Declare the version tag in a Bun consumer's package.json:

```json
{
  "dependencies": {
    "outcome": "github:ggonzalesd/outcome#v0.1.1"
  }
}
```

Run `bun install` and commit the consumer's `bun.lock`. Public imports remain `outcome`,
`outcome/result`, and `outcome/option`. The consumer owns its Bun cache and shared-store settings;
the formatter and other development dependencies are not installed for consumers.

Published tags stay fixed. v0.1.0 remains available for consumers pinned to that version.
