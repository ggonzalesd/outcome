# Outcome v0.1.0

First functional Bun/TypeScript version of the maintainer's Result and Option class library.
Distributed from https://github.com/ggonzalesd/outcome under MIT, with no runtime dependencies.

## Included

- Result and Option classes with the reference's PascalCase static methods and camelCase instance
  methods, including WhenNone, Join/Tuple, Zip, Switch, and Collapse.
- Strict inference for tuple positions, record values, error unions, functional composition, and
  nullable input. Try and Promise capture async failures as unknown unless an error mapper is given.
- Frozen wrappers and Result plain state; payloads remain by reference. Result unwrap throws its
  original error, while absent Option unwrap raises UnwrapError.
- Original behavior tests, regression checks, compile-time contracts, and real packed-package
  installation into an independent consumer. The verification suite contains 187 runtime tests.
- TypeScript source exports through outcome, outcome/result, and outcome/option. Bun 1.4.2 is the
  tested development/runtime baseline. A JavaScript distribution for other runtimes is not included.

## Install

Declare the version tag in a Bun consumer's package.json:

```json
{
  "dependencies": {
    "outcome": "github:ggonzalesd/outcome#v0.1.0"
  }
}
```

Run bun install and commit the consumer's bun.lock. Import public classes normally:

```ts
import { Option, Result } from "outcome";

const value = Result.Ok(Option.Some(21))
  .whenNone(() => "missing")
  .map((number) => number * 2)
  .unwrap(); // 42
```

The consumer controls its Bun cache and shared-store settings; installation requires no build hooks.
Published tags stay fixed. Future versions receive new tags instead of replacing v0.1.0.
