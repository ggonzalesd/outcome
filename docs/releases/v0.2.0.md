# Outcome v0.2.0

Adds exhaustive Result matching and a compact ESM release package. Existing source-tag imports
and public class APIs remain available.

## Changes

- `result.match({ success, failure })` executes the active branch and returns its output directly.
  `Result.Match` provides the corresponding curried function. Branches may return different types
  or void; thrown exceptions propagate.
- The release archive contains one minified ESM bundle and TypeScript declarations. It preserves
  the root, `outcome/result`, and `outcome/option` entries and their shared class identity.
- The archive includes the license and package metadata without source files or runtime
  dependencies. It does not require an installation-time build.

## Install

For the compact release package, declare the release asset URL in a Bun consumer:

```json
{
  "dependencies": {
    "outcome": "https://github.com/ggonzalesd/outcome/releases/download/v0.2.0/outcome-0.2.0.tgz"
  }
}
```

For the existing source distribution, use `github:ggonzalesd/outcome#v0.2.0`. These are different
distribution artifacts: the GitHub dependency uses the tagged repository snapshot, not the
release asset. Run `bun install` and commit the consumer's lockfile. Node and browser support have
not been established by the Bun consumer checks.
